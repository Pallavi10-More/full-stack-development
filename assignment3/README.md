# Assignment 3 - E-Commerce Fashion Store

This is a dynamic e-commerce website for a fashion store built using HTML, CSS, JavaScript, and Bootstrap CDN.

## Features

- **Responsive Design**: Uses Bootstrap for mobile-friendly layout.
- **Dynamic Product Listing**: Products are loaded dynamically from JavaScript.
- **Shopping Cart**: Add/remove items, view cart in a modal, calculate total.
- **Checkout**: Basic checkout functionality with alert confirmation.

## Files

- `index.html` - Main HTML structure with Bootstrap integration.
- `style.css` - Custom styles for the theme.
- `script.js` - JavaScript for dynamic product rendering and cart functionality.
- `welcome.jpg` - Background image for hero section.

## How to Run

1. Open `index.html` in a web browser.
2. Browse products and click "Add to Cart".
3. Click the cart icon in the navbar to view cart.
4. Use "Checkout" to complete purchase.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5 CDN

## Customization

- Edit `products` array in `script.js` to add/remove products.
- Modify styles in `style.css` for theme changes.
- Update hero background in `index.html`.
