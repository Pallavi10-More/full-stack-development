# Assignment 2 - Portfolio Page

This folder contains a simple personal portfolio website built with HTML and CSS. The page showcases the following sections:

- **Home** with profile image and introduction
- **About** brief description
- **Skills** list of technical skills
- **Resume** download link (placeholder)
- **Projects** project summaries
- **Contact** links for email, LinkedIn, and GitHub

## Files

- `index.html` – main HTML document containing the structure and content.
- `style.css` – custom stylesheet used by the page.

> Note: The portfolio currently uses placeholder images and links. Update these as needed.

## Usage

To view the page, simply open `index.html` in a web browser. No server setup is required since the site is entirely static.

## Customization

- Replace `Pallavi.jpg` with your own image and adjust the `src` attribute in `index.html`.
- Update project descriptions and links in the `Projects` section.
- Modify `style.css` to change colors, layout, and typography.
